== printf varargs at the call site ==
main does `sub rsp,0x40`, so rsp = rbp-0x40 when printf(user) is called with
rdi = user and al = 0. Under SysV the first five conversion arguments come from
rsi, rdx, rcx, r8 and r9, so %6$ is the first stack qword.

  %6$   [rsp+0x00]  rbp-0x40   padding
  %7$   [rsp+0x08]  rbp-0x38   char *user, the scanf("%ms") allocation
  %8$   [rsp+0x10]  rbp-0x30   FILE *fp
  %9$   [rsp+0x18]  rbp-0x28   char *p = buf, stored by lea rax,[rbp-0x20]
  %10$  [rsp+0x20]  rbp-0x20   flag bytes 0..7
  %11$  [rsp+0x28]  rbp-0x18   flag bytes 8..15
