Architecture

Vaultkeeper is a single-appliance backup & restore engine. Requests flow through the public API into the restore engine, which stages imports in an isolated vk_restore schema before reconciling them against the live vaultkeeper schema.

Components

  • Public API — job telemetry, catalog search, schedules, metrics, status.
  • Restore console — session-addressed upload → import → file-tree restore.
  • Restore engine — replays database.sql, reconciles staging tables.
  • Replication — mirrors staging manifests to sibling nodes.

Access tokens

The appliance issues short-lived, scoped access tokens for the console and for signed download links. Tokens are signed server-side and verified on every request; secrets are held on the appliance and never rendered in the UI.

Scopes

Roles are ranked guest < viewer < operator < maintainer < admin. Higher scopes unlock the maintenance actions in the restore console; day-to-day operators only need the standard restore workflow.
