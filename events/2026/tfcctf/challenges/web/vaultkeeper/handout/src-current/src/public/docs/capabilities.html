Capabilities & scopes

Each restore session carries a single scope. Requesters start with a standard scope for uploading and inspecting a recovery bundle; the maintenance actions are available to higher scopes managed from the console.

guestread job telemetry, upload a bundle
viewerread catalog, metrics, audit tail
operatorrun system file restore
maintainerimport a database manifest
adminmanage the console and replication

Bundle compatibility

Vaultkeeper reads recovery bundles exported by 4.x appliances. Bundles from older releases are still accepted; only their plain data fields are carried forward during import.
