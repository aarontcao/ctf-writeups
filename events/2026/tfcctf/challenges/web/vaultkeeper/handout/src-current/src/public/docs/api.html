Bundles are uncompressed archives containing database.sql and the site file tree. The restore queue is exposed read-only at /api/jobs.php.

Console API

  • GET /api/bundle_index.php?kind=&sort=&dir= — sortable index of catalogued bundles.
  • POST /api/session_ticket.php — mint a console session ticket; GET ?ticket= resolves it.
  • POST /api/render_template.php — preview an alert notification template.
  • POST /api/import_checkpoint.php — migrate a pre-4.0 console checkpoint export.
  • GET/POST /api/annotations.php?ref= — operator notes for a restore run.
