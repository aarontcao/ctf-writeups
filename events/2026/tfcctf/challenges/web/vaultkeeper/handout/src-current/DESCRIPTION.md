# Vaultkeeper

**Category:** Web  **Difficulty:** Hard

Vaultkeeper is a self-hosted **backup & restore appliance**. Schedule snapshots of your databases
and file trees, ship them to any destination, and roll an entire site back in minutes. Operators can
request a self-service restore and re-import a recovery bundle from the restore console.

**Connect:** `http://<HOST>:8080`

Flag format: `TFC{...}`
